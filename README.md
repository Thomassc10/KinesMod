A Minecraft Forge mod with some features for Hypixel SkyBlock. This was created because I could only find some features in ChatTriggers modules, which is bad for performance. There are many other random features too.

**Features**

<details>
<summary>Commands</summary>
  - /kines -> opens main menu
  - /kines edit -> edit GUI locations
</details>
<details>
  
<summary>Misc</summary>

- Toggle Sprint
- Skip Front Camera
- Filter Messages
- Remove Scoreboard Scores
- Remove Falling Blocks
- God Pot Expired
- Auto Leave
- Hide Dead Entities

</details>

<details>
<summary>Overlays</summary>

- Remove Health
- Remove Food Bar
- Remove Armor
- Remove Crosshair (Third person)

</details>

<details>
<summary>Mining</summary>

- CH Waypoints
- Mining Speed Boost Ready
- Hide Sky Mall
- Show Sky Mall Buff
- Gemstone Regen Timer
- CH Pass Renew

</details>

<details>
<summary>Crimson Isle</summary>

- Lord Jawbus Spawned
- Alert Vanquisher Spawn
- Auto Invite&Warp
- Auto Accept
- Ghast Spawn

</details>


<details>
<summary>Kuudra</summary>

- Waypoint for Supplies/Fuels
- Highlight Safe Spots
- Hide Name Tags
- Show Unfinished Supply Piles

</details>

<details>
<summary>The End</summary>

- Stop Enderman Teleportation
- Endstone Protector Spawned
- Move Enderman Tag Downwards

</details>

<details>
<summary>Events</summary>

- Great Spook
  - Primal Fear Spawned
  - Solve Math Teacher
  - Primal Fear Timer
- Diana
  - Alert Inquisitor

</details>

More for Slayers, Garden, HUD (TPS), Bestiary, GUI...
